\noindent\textbf{Title:} A High-Resolution Finite-Difference Framework for Steady Continuation and Finite-Window Unsteady Dynamics up to $Re = 100{,}000$ in 2D Lid-Driven Cavity Flows

\vspace{0.5em}
\noindent\textbf{Author:} Kartikey Singh (ORCID: \url{https://orcid.org/0009-0009-1973-7532})

\vspace{1em}
\noindent\textbf{Highlights (Each bullet strictly $\le 85$ characters including spaces):}

\begin{itemize}
    \item Exact $\mathcal{O}(N^2 \log N)$ DST-I Poisson solver eliminates iterative residual drift.
    \item Pure central differencing retains zero numerical viscosity for $Re \le 50{,}000$.
    \item Interior hybrid scheme stabilizes corner singularity at $Re = 100{,}000$.
    \item Core vorticity profiles show qualitative alignment with Batchelor theorem.
    \item Unsteady marching on $513 \times 513$ grids resolves finite-window shedding modes.
\end{itemize}
