\vspace{0.5em}
\noindent \textbf{Significance and Key Contributions:} \\
The incompressible 2D lid-driven cavity flow remains the canonical proving ground for computational fluid dynamics. However, established benchmarks stagnate at $Re \le 10,000$ (Ghia et al., 1982) or $Re \le 25,000$ (Erturk et al., 2005). In this manuscript, we push the numerical and scientific frontiers through several key contributions:
\begin{enumerate}
    \setlength{\itemsep}{0.2em}
    \setlength{\parskip}{0pt}
    \item \textbf{Exact Spectral Poisson Acceleration:} We integrate an exact Discrete Sine Transform (DST-I) Poisson solver operating at optimal $\mathcal{O}(N^2 \log N)$ complexity, eliminating iterative residual drift, pressure-velocity decoupling, and numerical dissipation.
    \item \textbf{Asymptotic Core Vorticity Homogenization ($Re \to 100,000$):} We compute stationary continuation solutions up to $Re = 100,000$ on uniform Cartesian grids ($513 \times 513$) and a high-resolution grid ($1025 \times 1025$, $1,050,625$ nodes). We observe core vorticity behavior qualitatively consistent with Batchelor's (1956) asymptotic theorem through the plateau $\omega_0 \approx -2.54$ alongside symmetric mid-plane alignment ($x_c \to 0.50000$).
    \item \textbf{Interior Hybrid Differencing \& Numerical Dissipation Mapping:} We incorporate an interior hybrid differencing scheme at $Re = 100,000$ ($Pe = 195.3$) that regularizes corner singularity dispersion with added numerical viscosity ratio $\bar{\nu}_{\text{art}}/\nu = \frac{1}{4}[Pe_x \mathbf{1}_{Pe_x > 2} + Pe_y \mathbf{1}_{Pe_y > 2}]$, yielding $1.485$ in the core and $48.83$ at the lid on $513 \times 513$ (dropping to $0.74$ and $24.46$ on $1025 \times 1025$), with pure central differencing strictly preserved everywhere for all $Re \le 50,000$.
    \item \textbf{Extended Unsteady Marching \& Shedding Dynamics:} Through time-accurate marching on $513 \times 513$ meshes ($t = 16.0$--$22.0$ c.t.u., $St \equiv fL/U$), we resolve periodic vortex shedding ($Re = 10,000$, $St = 0.6249 \pm 0.0416$, $7.50$ cycles), modulated multi-frequency dynamics ($Re = 15,000$, $St = 0.5364 \pm 0.0278$, $9.66$ cycles), and nonlinear vortex shedding across high Reynolds numbers: $Re = 25,000$ ($St = 0.0953 \pm 0.0281$, $1.70$ cycles), $Re = 50,000$ ($St = 0.2581 \pm 0.0300$, $4.30$ cycles), and $Re = 100,000$ ($St = 0.1908 \pm 0.0379$, $2.52$ cycles).
    \item \textbf{Scientific Reproducibility \& Open Benchmarks:} We openly release 30 full 2D coordinate/flow field datasets, phase trajectory scripts, and automated visualization tools under the MIT License with permanent Zenodo DOIs.
\end{enumerate}
